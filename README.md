# AnsariVPN

Chrome extension VPN with 10 proxy regions. Switch your browsing region from a single toolbar popup.

## Install
1. Open `chrome://extensions`.
2. Enable Developer mode (top right).
3. Click **Load unpacked**.
4. Select this repo folder.

## Proxies
- US
- UK
- Canada
- Germany
- Netherlands
- Japan
- Singapore
- Australia
- Brazil
- India
